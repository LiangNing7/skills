# 保存知识与提案

## 保存指定内容

读取知识库 AGENTS.md，确认本次保存意图、内容范围与现有页面。优先更新能承载该内容的页面，文件路径用英文，正文用中文。

- 来源支持的知识可进入正式页面；用户观点注明其来源与讨论日期。
- 尚未采用的项目设计、论文研究方案保存到按需建立的 wiki/drafts/，status: proposed。记录其拟合并页面和依据，不把讨论措辞改成已决定的事实。
- 用户明确采用并要求保存时，使用 wiki-publish 的合并流程；不重复索取已经给出的授权。
- 对话来源可以标为用户陈述与讨论日期，不伪造外部文献或实际项目结果。
- 正式内容变更时核对相关概念表、证据状态和研究概览，记录受影响结论及仍待核实项。更新入口、索引和维护记录；批次刷新本地 BM25、检查变更范围，再使用 wiki-sync。草稿不进入两种正式检索副本。

本 Skill 不替用户保存 OpenViking Memory。用户指定目标是 Memory 时转交 memory-curator。
