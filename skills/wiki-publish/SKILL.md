# 确认并合并知识草稿

## 合并确认的内容

读取知识库 AGENTS.md。一次“采用这个方案并保存”已经授权本次合并；尚未采用或尚未要求保存时，先在对话中讨论。

1. 阅读草稿、目标页面、相关来源和引用，核对用户实际确认的范围。
2. 合并确认的内容，保留仍有效的原文。旧结论被替代时记录依据和修订理由，未确认部分保持 proposed。
3. 正式页面使用 active，明确的项目决策可用 confirmed。已经完全合并的草稿标为 merged，仍保留其来源与历史。
4. 更新相关概念表、链接与入口，评估研究概览，记录受影响命题、更新范围和仍待核实项；批次刷新本地 BM25，并检查相关范围的结构及重要语义变更。
5. 用 wiki-sync 更新正式检索副本；同步失败报告待同步，保留本地已确认的知识。

原件和提取版按既定规则保护。博客公开发布是另一个任务，按其明确授权范围执行。
