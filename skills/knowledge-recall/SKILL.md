# 查阅知识与经验

## 获取相关上下文

先取得全局规则指定的知识库路径，并读取其中的 AGENTS.md。项目目录和主题按实际内容确定，示例名称不作为事实。

- 有具体来源路径时优先读取该页面；需要发现相关内容时，使用已注册的 openviking MCP 工具定向搜索正式 Wiki 与用户 Memory。
- 精确术语、API、错误信息及中文概念检索时，按 [检索协议](references/search.md) 使用 scripts/wiki-search.py；跨措辞问题可并用 OpenViking。先查相关主题概念表再选择正文，别名和搜索片段仅用于定位。
- 目录摘要和概览用于定位，关键结论应读取正文并回查其依据。无需机械地逐层读完全部目录。
- 通过 context_read 读取命中 URI；服务不可用时查看本地 wiki/index.md、项目入口，并用 rg 定向搜索。入口尚未创建时报告实际现状。
- 对正式 Wiki 命中，核对其 source_path 和本地同步记录中的内容版本。不同步的副本不能替代本地新内容。
- Wiki 摘要用于发现内容；关键依据沿来源链接直接查原件。PDF 用 #page=N 定位文件中从 1 开始的实际页序，并核对相关表格、公式和实验条件。已有提取版可辅助定位，无需为一次召回生成新的全文 Markdown。
- 读取 PDF 时可用 knowledge-ingest/scripts/read-pdf.py 输出选定页文字和来源链接；需要核验页面时将图像渲染到仓库外缓存，再用图像查看工具读取。原件路径以实际来源记录为准。
- Memory 作为带日期和适用范围的经验参考。内部决策核对确认的 Wiki；软件事实核对当前代码和官方资料。

## 输出

用相关上下文完成用户任务，列出改变判断的来源。读取结束本身不授权保存、同步、写 Memory 或修改技能。

本目录的 scripts/mcp-proxy.py 是受限的 OpenViking MCP 客户端入口，仅暴露检索、读取、健康检查和明确授权的记忆写入。
