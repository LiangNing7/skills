# 保存明确授权的经验

## 保存经验

读取全局规则与知识库 AGENTS.md，核对当前明确的 Memory 保存要求。自动发现本 Skill 不等于获得保存授权。

- 选取本次明确指定的经验或偏好，记录日期、来源、适用项目和验证依据。
- 项目正式知识和决策以 Wiki 为准；Memory 可以引用其位置，保留经历和操作经验。
- 提案、推测和过时状态保留其限定，不改写为已验证结论。
- 使用已注册的 openviking remember 工具，并且仅在当前授权覆盖提交内容时设置 authorized=true。
- 读取后台任务结果，确认处理成功及实际可召回的内容。提交成功或返回 task_id 不等于记忆已完成。
- 服务不可用或提取失败时报告未保存，保持目标为 Memory。

删除、纠正记忆或升级 Skill 按各自明确指令执行。凭证和无关聊天不属于本次经验内容。
