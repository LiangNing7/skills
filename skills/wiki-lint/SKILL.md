# Wiki 健康巡检

先读取目标知识库 AGENTS.md 与相关入口，确定范围及是否已获修复授权。默认只输出报告，不保存报告、写日志或修复页面。

1. 使用全局入口指定的 Python 运行 `scripts/wiki-lint.py --vault <vault> --scope <wiki-path>`。省略 scope 检查整个正式 Wiki；输出 JSON，`--format markdown` 可读报告。程序依赖同时部署的 knowledge-recall 页面解析模块。
2. 程序只核验结构，输出 error／warning／info 和 certain／candidate／unverified；术语频次属于候选，不自动建页。exit 1 表示结构错误，exit 2 表示执行失败，不能混为语义结论。
3. 读取 [语义审查协议](references/semantic-review.md)，打开相关正文并回查关键原件。逐条核对内容深度、链接相关性、命题条件、来源时效及证据缺口。范围大时按主题检查，说明实际语义审阅范围。
4. 合并报告：位置、问题、依据、严重程度、确定程度、建议。结构通过不代表语义健康；无法仲裁的冲突保留待核实。
5. 用户已授权修复时，在授权范围修复明确问题，重新检查相关范围，维护概念表、概览及日志，并刷新检索与同步。普通巡检不要求用户重新批准已授权动作；也不默认获得修复授权。

检查器严格只读原件与页面，不创建仓库内缓存、不执行 Markdown 中的代码、不调用生成模型或 Memory。只读巡检不执行 wiki-sync。详细项目规则按 AGENTS.md 的任务路由读取。
