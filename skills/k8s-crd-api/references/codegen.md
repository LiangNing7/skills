# Code generation

## Hand-written vs generated

| File | Owner |
|---|---|
| `doc.go`, `register.go`, `<kind>_types.go`, `condition_types.go`, `condition_consts.go`, `common_types.go`, `defaults.go`, `validation/`, `install/`, `OWNERS`, `fuzzer/` | **hand-written (you write)** |
| `zz_generated.deepcopy.go` | `deepcopy-gen` |
| `zz_generated.conversion.go` | `conversion-gen` |
| `zz_generated.defaults.go` | `defaulter-gen` |
| `types_swagger_doc_generated.go` | `openapi-gen` |
| `generated.pb.go` / `generated.proto` | protobuf-gen (optional) |
| clientset / listers / informers | `client-gen` / `lister-gen` / `informer-gen` |
| applyconfigurations | `applyconfiguration-gen` |

Generators emit only mechanical, field-by-field boilerplate. Anything with
business semantics (types, defaults, validation, semantic conversion) is
hand-written. Never edit a `zz_generated.*` file by hand.

## doc.go markers drive generation

Internal:

```
// +k8s:deepcopy-gen=package
// +groupName=<group>
```

External:

```
// +k8s:openapi-gen=true
// +k8s:deepcopy-gen=package
// +k8s:conversion-gen=<internal pkg>
// +k8s:conversion-gen-external-types=<this pkg>
// +k8s:defaulter-gen=TypeMeta
// +groupName=<group>
```

## Common generator arguments

| Argument | Meaning |
|---|---|
| `--go-header-file <boilerplate>` | copyright header template |
| `--input-dirs` | packages to process |
| `--bounding-dirs` | deepcopy boundary (avoid generating external packages) |
| `--output-pkg` / `--output-dir` | client/lister/informer output (e.g. `pkg/generated/...`) |
| `--plural-exceptions` | irregular plural resource names |
| `--extra-peer-dirs` | conversion peers for cross-package types |

Generated files start with `//go:build !ignore_autogenerated` and
`// Code generated by <tool>. DO NOT EDIT.`; `verify-codegen` enforces that
committed output matches a fresh run.

## Execution strategy

1. Detect a repo script (`scripts/update-codegen.sh`, a `Makefile` target, or
   `hack/`). If present, run it.
2. Otherwise print the standard commands, e.g.:

```bash
deepcopy-gen --go-header-file <boilerplate> --bounding-dirs <module>,k8s.io/api --input-dirs <pkg>...
conversion-gen --go-header-file <boilerplate> --extra-peer-dirs k8s.io/api/core/v1 --input-dirs <external pkg>...
defaulter-gen --go-header-file <boilerplate> --input-dirs <external pkg>...
```

3. Run `gofmt` on everything and remind the user to run `verify-codegen`.
